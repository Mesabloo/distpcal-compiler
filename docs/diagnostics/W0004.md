# W0004: unnamed type-checking warning

A catch-all code. The type checker raised a non-fatal warning through a rule that has no dedicated
diagnostic of its own.

The message text carries the specific detail. Like `E0024`, this is a marker that the check which
fired has no narrower code.

## How to fix it

- Read the message: it describes what the checker noticed.
- If the case seems worth a named code, report it with the message and a reproducer.

## See also

- `E0024` — the same, for a fatal type-checking error.
