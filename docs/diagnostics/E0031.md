# E0031: type cannot be indexed

An indexing expression `e[e']` was used on something that is not a function, tuple, or sequence.

Those are the three indexable types. Anything else — an `Int`, a `Bool`, a set, a record — has no
`[_]` operation.

## Why it fires

```tla
---- MODULE Example ----
CONSTANTS
    \* @type: Address;
    PID

(*--algorithm Example {
    process (P = PID) {
    p1: print 5[1];
        goto Done;
    }
}*)
====
```

`5` is an `Int`; `5[1]` indexes into it.

## How to fix it

- Index only functions (`f[k]`), tuples (`t[1]`), and sequences (`s[i]`).
- For a record, use `.field`, not `["field"]`.
- For set membership, use `\in`, not indexing.

## See also

- `E0033` — a tuple index that is not a literal in range.
- `E0037` — a function was expected somewhere else.
