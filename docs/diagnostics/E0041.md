# E0041: type has no printable form

A `print` statement was given a value whose type is not showable.

`Int`, `Bool`, `Str`, `Address`, and any function, set, sequence, tuple, or record built only from
showable parts can be printed. A `Channel`, an operator value, or anything containing one cannot —
there is no text to show for it.

## Why it fires

```tla
---- MODULE Example ----
CONSTANTS
    \* @type: Address;
    PID

(*--algorithm Example {
    fifos
        \* @type: Channel(Int);
        ch;
    process (P = PID) {
    p1: print ch;
        goto Done;
    }
}*)
====
```

`ch` is a channel; a channel reference has no printable form.

## How to fix it

- Print a concrete value — a message you received on the channel, a counter — not the channel
  itself.
- Remove the `print`, or print a component that is showable.
