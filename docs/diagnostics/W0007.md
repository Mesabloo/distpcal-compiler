# W0007: unused @mailbox

A process declares a `@mailbox` but contains no `receive`, so the declaration is dropped.

A `@mailbox` says "this process listens on this channel". A process that never receives is not
listening on anything, so the annotation has no effect. Dropping it is what makes the internal
`mailbox` field mean exactly "this process receives, on this channel" — `.some c` iff the process
receives.

## Why it fires

```tla
---- MODULE Example ----
CONSTANTS
    \* @type: Address;
    PID

(*--algorithm Example {
    fifos
        \* @type: Channel(Int);
        ch;
    (* @mailbox: ch; *) process (P = PID)
        variables
        \* @type: Int;
        x = 0;
    {
    p1: send(ch, 1);
        goto p2;
    p2: x := 1;
        goto Done;
    }
}*)
====
```

The process `send`s on `ch` but never `receive`s, so its `@mailbox: ch` does nothing.

## How to fix it

- Remove the `@mailbox` if the process only sends.
- If it should receive, add the `receive` — a receiving process *must* have a `@mailbox` (`E0064`),
  so the annotation is not wrong, just premature.
- Silence with `-Wno-unused-mailbox`.

## See also

- `E0064` — the mirror case: a `receive` with no `@mailbox` (an error).
