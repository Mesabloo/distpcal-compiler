# E0063: process set mailbox not indexed by 'self'

A process *set* — `process (P \in S)` — receives from a channel whose index path does not mention
`self`, so every instance in the set drains the same FIFO.

`process (P \in S)` creates one instance per element of `S`. If they all `receive` from the same
`ch`, they compete for the same messages, and no instance can rely on receiving the ones meant for
it. Indexing by `self` — `ch[self]` — gives each instance its own FIFO.

A `process (P = e)` process has exactly one instance and needs no index.

## Why it fires

```tla
---- MODULE Example ----
CONSTANTS
    \* @type: Set(Address);
    PIDs

(*--algorithm Example {
    fifos
        \* @type: Channel(Int);
        ch;
    (* @mailbox: ch; *) process (P \in PIDs)
        variables
        \* @type: Int;
        x = 0;
    {
    p1: receive(ch, x);
        goto Done;
    }
}*)
====
```

Every instance of `P` receives from the single channel `ch`.

## How to fix it

- Declare the channel indexed and receive on `ch[self]`: `fifos ch[PIDs];` with
  `@mailbox: ch[self]` and `receive(ch[self], x)`.

- `E0007` — a malformed `@mailbox` expression.
