# E0050: process-local channel declaration

A process declares its own `channels` or `fifos`.

Channels connect processes to each other, so they are declared once at algorithm level, never
inside a single process. A process-local channel would have nothing to connect to.

## How to fix it

- Move every `channels`/`fifos` declaration to algorithm level, outside all processes.

- `E0051` — an algorithm-level `variables` block: shared *state* is disallowed for the same
  reason.
- `E0049` — a `variables` entry with a channel type.
