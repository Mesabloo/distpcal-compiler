# E0040: channel type expected

A position that requires a channel was given something else.

Two cases: a `channels`/`fifos` entry whose mandatory `@type` is not `Channel(τ)` (or
`_ -> Channel(τ)` for an indexed one), and a `send`/`receive`/`multicast` whose channel argument
does not resolve to a channel type.

## Why it fires

```tla
---- MODULE Example ----
CONSTANTS
    \* @type: Address;
    PID

(*--algorithm Example {
    fifos
        \* @type: Int;
        ch;
    process (P = PID) {
    p1: skip;
    }
}*)
====
```

`ch` is declared with `fifos` but annotated `Int`, not `Channel(Int)`.

## How to fix it

- Annotate a channel declaration as `Channel(τ)`, or `_ -> Channel(τ)` when it is indexed
  (`ch[self]`).
- Pass an actual channel — a `channels`/`fifos` name — as the channel argument of
  `send`/`receive`/`multicast`, not an ordinary variable.

## See also

- `E0042` — a channel's declared element type is not sendable.
- `E0048` — a channel referenced inside an ordinary expression.
