# E0015: write to a 'with'-bound name

A statement assigns to, or receives into, a name bound by an enclosing `with`.

A `with`-bound name is a fixed local binding to one value, not a process variable with state to
update. Writing to it is meaningless. This covers both `x := e` and `receive(ch, x)` — a
`receive`'s target counts as a write — and applies to any enclosing `with`, not just the
innermost.

## Why it fires

```tla
---- MODULE Example ----
(*--algorithm Example {
    variable y = 0;
    process (P = 0) {
    p1: with (x = 3) {
            x := 9;
        };
        goto p1;
    }
}*)
====
```

`x` is bound by `with (x = 3)`; `x := 9` tries to write it.

## How to fix it

- Write to a `variables` entry instead. If you need a mutable local, declare it in the process's
  `variables` and drop the `with`.
- If the value really is fixed, you do not need to assign it — just use `x`.
