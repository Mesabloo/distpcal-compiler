# E0065: duplicate process name

Two processes of one algorithm carry the same name.

A process is dispatched by name: a `goto`, and the run itself, find the process by name and there
must be exactly one. Two processes with the same name cannot be told apart.

This is separate from `E0046` (duplicate declaration): process names are in no declaration scope —
a process and a variable may share a name freely — but they must be distinct among themselves.

## Why it fires

```tla
---- MODULE Example ----
CONSTANTS
    \* @type: Address;
    PID1,
    \* @type: Address;
    PID2

(*--algorithm Example {
    process (P = PID1)
        variables x = 0;
    {
    p1: x := 1;
    }

    process (P = PID2)
        variables y = 0;
    {
    q1: y := 1;
    }
}*)
====
```

Both processes are named `P`.

## How to fix it

- Give each process a distinct name.
- To run the same body as several instances, use one process set: `process (P \in {PID1, PID2})`.

## See also

- `E0046` — a name declared twice in one scope.
- `E0044` — a `goto` to an unknown label.
