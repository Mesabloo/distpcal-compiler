# E0001: unexpected character

The lexer reached a character that cannot begin any token.

Before the parser sees anything, the source is split into tokens. A character that no token starts
with — a stray control character, an unbalanced piece of punctuation the language does not use, a
literal tab where whitespace is expected — stops the lexer here.

## Why it fires

```tla
---- MODULE Example ----
EXTENDS→Naturals
====
```

A literal horizontal tab between `EXTENDS` and `Naturals` (shown as `→`). Tabs are rejected
wherever whitespace is expected, with their own message; use spaces.

## How to fix it

- Delete or replace the character the caret points at. If it is invisible, it is almost certainly
  a tab or another control character — retype the line with spaces.
- A non-ASCII letter or symbol pasted from elsewhere (a curly quote, a non-breaking space) lexes
  as unexpected too; replace it with its ASCII form.
