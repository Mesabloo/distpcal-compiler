# E0048: channel in an ordinary expression

A channel reference appears somewhere other than the channel argument of `send`/`receive` or the
target of `multicast`.

A channel is a communication endpoint, not a value. It has no meaningful use inside an expression
— even one that type-checks, like `ch = ch`. Restricting where a channel name may appear is what
keeps the compiled processes from sharing anything but messages.

## Why it fires

```tla
---- MODULE Example ----
CONSTANTS
    \* @type: Address;
    PID

(*--algorithm Example {
    fifos
        \* @type: Channel(Int);
        ch;
    process (P = PID) {
    p1: assert ch = ch;
        goto Done;
    }
}*)
====
```

`ch = ch` uses the channel inside an `assert` expression.

## How to fix it

- Use `ch` only as `send(ch, e)`, `receive(ch, x)`, or `multicast(ch, ...)`.
- If you need to compare or store something about the channel, that is a sign the design wants an
  ordinary value passed alongside.

- `E0040` — a channel argument that is not a channel type.
