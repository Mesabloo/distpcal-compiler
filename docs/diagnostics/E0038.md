# E0038: tuple type expected

A multi-argument function definition — `f[x \in A, y \in B] == e` — has a `@type` whose domain is
not a tuple.

A function of several arguments has a tuple domain, so its type is `<<τ₁, τ₂>> -> τ`.

## How to fix it

- Give a multi-argument function a tuple domain: `\* @type: <<Int, Int>> -> Int;`.
- A one-argument function takes a plain domain: `\* @type: Int -> Int;`.
