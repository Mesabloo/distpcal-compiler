# W0001: 'fair' is ignored

A `fair` or `fair+` keyword on a process was parsed and then ignored.

`fair` / `fair+` state a fairness assumption — that an enabled process eventually runs. This
compiler does not act on fairness: neither the Go nor the Join Calculus runtime is fairness-aware.
The keyword is accepted so existing specs parse, but it has no effect on the generated program.

## Why it fires

```tla
---- MODULE Example ----
(*--algorithm Example {
    fair process (P = 0) {
    l1: skip;
    }
}*)
====
```

`fair process` — the `fair` is recorded and dropped.

## How to fix it

- Nothing needs fixing — the program is compiled, just without the fairness assumption. Silence
  the warning with `-Wno-fair`.
- If the algorithm's correctness depends on fairness, be aware the compiled program does not
  guarantee it.

## See also

- `E0002` — a `fair` with no `process` after it is a parse error, not this warning.
