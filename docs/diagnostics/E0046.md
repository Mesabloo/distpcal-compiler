# E0046: duplicate name

A name is declared twice in one scope where every name must be distinct.

This covers the algorithm's own declarations among themselves, and each process's local
declarations among themselves. The error is reported at the second declaration.

## Why it fires

```tla
---- MODULE Example ----
CONSTANTS
    \* @type: Address;
    PID

(*--algorithm Example {
    process (P = PID)
        variables x = 0, x = 1;
    {
    p1: skip;
    }
}*)
====
```

`x` is declared twice in the same `variables` block.

## How to fix it

- Rename or remove the duplicate.
- A process-local and an algorithm-level name colliding is `E0047` (shadowing), a different rule.

## See also

- `E0047` — an inner declaration shadowing an outer one.
- `E0065` — two processes sharing a name.
- `E0025` — a name with no declaration at all.
