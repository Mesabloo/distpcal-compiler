# E0029: set type expected

A position that requires a set was given something of another type.

The domain of a quantifier or a function literal (`\A x \in e`, `[x \in e |-> ...]`), the
right-hand side of `\in`, the argument of `UNION` or `SUBSET` — all require a `Set(_)`.

## Why it fires

```tla
---- MODULE Example ----
CONSTANTS
    \* @type: Address;
    PID

(*--algorithm Example {
    process (P = PID) {
    p1: assert \A x \in 5 : x = x;
        goto Done;
    }
}*)
====
```

`\A x \in 5` — the domain `5` is an `Int`, not a set.

## How to fix it

- Supply a set: `1..5`, `{1, 2, 3}`, a `CONSTANTS` set, `DOMAIN f`.
- A common slip is `x \in n` (a number) where `x \in 1..n` was meant.
