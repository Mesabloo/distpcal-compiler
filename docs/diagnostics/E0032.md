# E0032: unknown record field

A record access or update named a field that the record's type does not have.

The message lists the fields the type does have.

## Why it fires

```tla
---- MODULE Example ----
CONSTANTS
    \* @type: Address;
    PID

(*--algorithm Example {
    process (P = PID) {
    p1: print [a |-> 1].b;
        goto Done;
    }
}*)
====
```

`[a |-> 1]` has type `[a : Int]`, which has no `b`.

## How to fix it

- Use one of the fields the record actually has (see the message), or add the field to the record
  literal / its `@type`.
- A typo in the field name is the usual cause.

## See also

- `E0030` — `.` on something that is not a record.
- `E0019` — the field position is not an identifier.
