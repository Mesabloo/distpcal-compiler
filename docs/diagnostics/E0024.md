# E0024: unnamed type-checking failure

A catch-all code. The type checker rejected the program through a rule that has no dedicated
diagnostic of its own.

The message text carries the specific detail. This is less a code to look up than a marker that
the check which fired has no narrower code.

## How to fix it

- Read the message: it describes the actual problem.
- If the case seems like it should have its own diagnostic, report it with the message and a small
  reproducer, so a named code can be added.

## See also

- `W0004` — the same, for a non-fatal type-checking warning.
