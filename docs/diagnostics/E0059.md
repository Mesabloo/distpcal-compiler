# E0059: module name does not match file name

A file's `---- MODULE X ----` header names a module different from the file's own name.

TLA⁺ requires the two to agree: `EXTENDS Foo` looks for `Foo.tla` and reads the module named `Foo`
inside it. A mismatch means no other module can ever reach this one, however well it compiles on
its own.

## Why it fires

A file named `Example.tla` whose header reads:

```tla
---- MODULE Widget ----
====
```

The file is `Example.tla`; the module declares itself `Widget`.

## How to fix it

- Rename the file to match the module (`Widget.tla`), or the module to match the file
  (`---- MODULE Example ----`).
- Both parts of the report are equally suspect — check which name is the one you meant.

## See also

- `E0021` — an `EXTENDS`-ed module not found (often the downstream effect of this).
- `E0022` — a module name that resolves to more than one file.
