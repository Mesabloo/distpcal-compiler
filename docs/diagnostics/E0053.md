# E0053: temporal or action operator reachable from a statement

A temporal or action operator — `[]`, `<>`, `ENABLED`, `UNCHANGED`, `'` (prime), `^+`, `^*`, `^#`
— is reachable from the algorithm's executable code, directly or through a chain of operator or
function calls.

These operators describe whole behaviours over time, not a value to compute at one point in an
execution. A Distributed PlusCal algorithm is executable code, so none of them may appear where it
runs. The message says whether the operator is used directly or reached through a call path.

## Why it fires

```tla
---- MODULE Example ----
CONSTANTS
    \* @type: Address;
    PID

(*--algorithm Example {
    process (P = PID)
        variable x = 0;
    {
    p1: assert x' = x;
        goto Done;
    }
}*)
====
```

`x'` uses prime, an action operator, inside an `assert`. It type-checks on its own — well-formedness
is what rejects it.

## How to fix it

- Drop the temporal/action operator from the algorithm. Prime relates a state to its successor;
  inside executable code you just write the new value.
- If the operator is in an operator you call, that operator is not usable from the algorithm —
  inline the part you need without it.
