# E0049: channel-typed variable

A `variables` or `with` entry has a channel-shaped type.

`channels` and `fifos` are the only way to declare a channel. Giving an ordinary variable a
`Channel(τ)` type is a way around the rule that a channel may not appear in an expression
(`E0048`), so it is rejected too. No initialiser is needed to trigger this — the declared type
alone is the violation.

## Why it fires

```tla
---- MODULE Example ----
CONSTANTS
    \* @type: Address;
    PID

(*--algorithm Example {
    process (P = PID)
        variable (* @type: Channel(Int); *) ch;
    {
    p1: skip;
    }
}*)
====
```

`ch` is declared with `variable` but typed `Channel(Int)`.

## How to fix it

- Declare channels with `channels`/`fifos`, at algorithm level.
- If `ch` was meant to hold data, give it a data type.

## See also

- `E0048` — a channel used inside an expression.
- `E0051` — an algorithm-level `variables` block.
