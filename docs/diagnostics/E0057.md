# E0057: internal invariant violated in Computable2Guarded

A compiler bug, not a problem with your specification.

The pass that rewrites the computable algorithm into Guarded PlusCal — turning `if`/`while` into
`either`/`await`, sequentialising parallel assignments, flattening and reordering guards — relies
on shape guarantees its earlier steps establish (a `while` immediately preceded by a labelled
block, for one). This diagnostic fires when one of those did not hold. A program that gets this
far through the pipeline should never trigger it.

## Why it fires

An invariant this pass depends on was broken before the offending step ran. The message names the
specific one.

## How to fix it

- Report it, with the specification and the message text.
