# W0002: unused annotation

A well-formed annotation sits where nothing reads it.

The annotation parses and is of a kind the site could carry, but nothing consumes it — a `@type`
where the type is already fixed some other way, a marker with no role at that position. It is
dropped, and this warning records that it was.

## How to fix it

- Remove the annotation; it has no effect.
- Silence with `-Wno-unused-annotation`.
