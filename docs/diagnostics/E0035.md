# E0035: wrong number of arguments

An operator was applied to more or fewer arguments than its type has parameters.

## Why it fires

```tla
---- MODULE Example ----
EXTENDS Naturals

CONSTANTS
    \* @type: Address;
    PID

\* @type: (Int, Int) => Int;
Add(a, b) == a + b

(*--algorithm Example {
    process (P = PID) {
    p1: print Add(1);
        goto Done;
    }
}*)
====
```

`Add` takes two arguments; `Add(1)` supplies one.

## How to fix it

- Supply exactly as many arguments as the operator's `@type` declares.
- If the operator should take a different number, change its definition and its annotation
  together.

## See also

- `E0039` — a higher-order parameter used at an arity its declared type does not allow.
- `E0034` — something used as an operator that is not one.
