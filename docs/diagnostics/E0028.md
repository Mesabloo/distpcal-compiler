# E0028: cannot infer a type

An expression appears where its type has to be inferred, and there is no way to infer it.

Some constructs — the empty set `{}`, an unbounded `CHOOSE x : P` — only make sense when the
surrounding context already fixes what type they should have. Used somewhere the context fixes
nothing (a `print` argument, a bare `assert`), there is no type to give them.

## Why it fires

```tla
---- MODULE Example ----
CONSTANTS
    \* @type: Address;
    PID

(*--algorithm Example {
    process (P = PID) {
    p1: print CHOOSE x : x = x;
        goto Done;
    }
}*)
====
```

`print` fixes no type for its argument, and unbounded `CHOOSE` has no type of its own.

## How to fix it

- Put the expression where a type is expected: assign it to an annotated variable, or annotate the
  enclosing declaration.
- For `CHOOSE`, give it a domain: `CHOOSE x \in S : P`.
