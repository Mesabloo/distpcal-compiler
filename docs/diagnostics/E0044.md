# E0044: unknown label

A `goto` targets a label that is not defined anywhere in its process.

Every `goto` names a labelled block in the same process. `Done` always counts as defined — it is
the implicit terminal label. Any other name has to appear as a `label:` somewhere in that
process's body.

## Why it fires

```tla
---- MODULE Example ----
CONSTANTS
    \* @type: Address;
    PID

(*--algorithm Example {
    process (P = PID)
        variable x = 0;
    {
    p1: x := 1;
        goto p2;
    }
}*)
====
```

`goto p2` — there is no `p2:` in this process.

## How to fix it

- Check the spelling against the labels the process actually defines.
- To end the process, `goto Done`.
- A `goto` cannot cross into another process's labels — each process's labels are its own.

## See also

- `E0045` — `Done` redefined as an ordinary label.
- `E0065` — two processes sharing a name, which also confuses label resolution.
