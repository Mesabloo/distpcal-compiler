# E0010: unlabelled statement

A statement has no label reachable above it, so it belongs to no labelled atomic block.

Every statement in a process body runs as part of some labelled block — the block is the unit of
atomicity and the target of `goto`. A statement before the process's first label has no block to
join.

## Why it fires

```tla
---- MODULE Example ----
(*--algorithm Example {
    variable x = 0;
    process (P = 0) {
        x := 1;
    p1: print x;
        goto p1;
    }
}*)
====
```

`x := 1` comes before `p1`, the thread's first label.

## How to fix it

- Put a label before the first statement of the process body: `p1: x := 1;`.
- If the statement was meant to be part of a later block, move it after that block's label.

## See also

- `E0009` — a `goto` followed by unlabelled statements.
- `E0013` — a `while` with no label immediately before it.
