# E0016: annotation not accepted here

An annotation is well-formed, but the site it sits on does not take that kind of annotation.

Each annotation has its place: `@type` on a declaration or binder, `@mailbox` immediately before a
`process`, `@parameter` on a process-local variable initialised with `\in`. Put one somewhere
else and it is rejected — the message names what the site does accept.

## Why it fires

```tla
---- MODULE Example ----
(*--algorithm Example {
    process (P = 0)
        variable (* @parameter *) x = 0;
    {
    p1: skip;
    }
}*)
====
```

`@parameter` marks a caller-supplied input, which only makes sense for an `\in`-initialised
variable. `x = 0` is a single fixed value.

## How to fix it

- Move the annotation to a site that accepts it, or change the site — e.g. `x \in {0, 1}` for
  `@parameter`.
- `@mailbox` goes directly before `process`, not on a variable; `@type` goes on the declaration,
  not the process.
