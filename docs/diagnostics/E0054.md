# E0054: unbounded quantifier reachable from a statement

An unbounded quantifier — `\A x : P`, `\E x : P`, or `CHOOSE x : P` with no domain — is reachable
from the algorithm's executable code.

Without a domain, evaluating the quantifier means ranging over every value there is. That has no
finite runtime meaning. (Unbounded `\A`/`\E` usually fail earlier, at `E0027`, for having no type;
an unbounded `CHOOSE` whose binder is annotated type-checks and reaches this check.)

## Why it fires

```tla
---- MODULE Example ----
CONSTANTS
    \* @type: Address;
    PID

(*--algorithm Example {
    process (P = PID)
        variable (* @type: Int; *) n = CHOOSE m : m = m;
    {
    p1: skip;
    }
}*)
====
```

`CHOOSE m : m = m` has no domain.

## How to fix it

- Give the quantifier a finite domain: `CHOOSE m \in S : P`, `\A x \in 1..n : P`.

## See also

- `E0027` — an unbounded `\A`/`\E`, rejected earlier for having no type to infer.
- `E0053` — a temporal or action operator reachable from a statement.
