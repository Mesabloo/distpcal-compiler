# E0006: malformed expression annotation

The text inside an annotation that takes an expression — `@mailbox` — does not parse.

## Why it fires

```tla
---- MODULE Example ----
CONSTANTS
    \* @type: Set(Address);
    PIDs

(*--algorithm Example {
    fifos
        \* @type: Channel(Int);
        ch[PIDs];
    \* @mailbox: ch[;
    process (P \in PIDs) {
    p1: receive(ch, x);
        goto Done;
    }
}*)
====
```

`ch[` is never closed, so the `@mailbox` expression does not parse.

## How to fix it

- Close every bracket and parenthesis in the annotation.
- The expression must be a channel reference: a name, optionally indexed — `ch`, `ch[self]`,
  `ch[self, k]`.

## See also

- `E0005` — the same, for a type annotation (`@type`).
- `E0007` — the expression parses but is not the `var[...]` shape `@mailbox` requires.
