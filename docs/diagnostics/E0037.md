# E0037: function type expected

A function definition — `f[x \in S] == e` — carries a `@type` annotation that is not a function
type.

A function's type is written with `->`: `Int -> Int`. `=>` is the operator arrow, a different
construct.

## How to fix it

- Annotate a function definition with a function type: `\* @type: Int -> Int;`.
- Check the definition is meant to be a function (`[x \in S]`), not an operator (`(x)`).
