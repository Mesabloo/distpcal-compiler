# E0005: malformed type annotation

The text inside a `@type` annotation does not parse as a type.

Type annotations have their own small grammar — `Int`, `Bool`, `Str`, `Set(τ)`, `Seq(τ)`,
`τ -> τ'`, `(τ, …) => τ'`, `<<τ, …>>`, `[a : τ, …]`, `Channel(τ)`. Anything outside it stops here.

## Why it fires

```tla
---- MODULE Example ----
CONSTANTS
    \* @type: Set(;
    PID
====
```

`Set(` is never closed, so the type does not parse.

## How to fix it

- Check the type against the grammar above: balanced parentheses and brackets, a known base type
  at the leaves.
- `->` is the function arrow, `=>` the operator arrow — mixing them, or writing `Function` /
  `Sequence` in full, does not parse.
