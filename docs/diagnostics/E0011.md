# E0011: label inside a 'with' body

A label appears inside a `with` body, which cannot contain one.

A `with` binds a name to a value for the duration of one atomic step. A label marks a point where
execution can pause and another process can run — which would leave the `with` binding half-alive
across a reschedule. The two cannot coexist, so a label inside a `with` is rejected.

## Why it fires

```tla
---- MODULE Example ----
(*--algorithm Example {
    variable x = 0;
    process (P = 0) {
    p1: with (y = 1) {
    p2:     x := y;
        };
        goto p1;
    }
}*)
====
```

`p2` sits inside the `with (y = 1)` body.

## How to fix it

- Move the labelled statement out of the `with`. If it needs `y`, recompute or rebind it outside.
- A `with` body is meant to be a single atomic step; if you need a pause in the middle, it should
  not be a `with`.
