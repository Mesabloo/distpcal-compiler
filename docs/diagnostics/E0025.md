# E0025: unbound variable

A name is used where nothing in scope binds it.

The type checker looked the name up — in the local bindings, the process and algorithm
declarations, the module's own definitions, and everything brought in by `EXTENDS` — and found
nothing.

## Why it fires

```tla
---- MODULE Example ----
CONSTANTS
    \* @type: Address;
    PID

(*--algorithm Example {
    process (P = PID) {
    p1: print total;
        goto Done;
    }
}*)
====
```

`total` is never declared or defined.

## How to fix it

- Check the spelling and case.
- Declare it: a `CONSTANTS`/`VARIABLE` entry, an operator or function definition, or a process
  `variables` entry, depending on what it is.
- If it comes from another module, add the `EXTENDS` clause that brings it in.

## See also

- `E0046` — a name declared twice in one scope.
- `E0047` — a declaration that shadows an outer one.
