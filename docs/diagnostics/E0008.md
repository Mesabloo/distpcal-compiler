# E0008: misplaced '@'

`@` appears outside the `EXCEPT` update it refers to.

Inside `[f EXCEPT ![i] = e]`, `@` stands for the function's old value at that index. It has no
meaning anywhere else — there is no old value to name.

## How to fix it

- Use `@` only on the right-hand side of an `EXCEPT` update: `[f EXCEPT ![i] = @ + 1]`.
- `@` is not an identifier; if you meant a name, write it out.
