# E0003: wrong number of annotation arguments

An annotation was given more or fewer arguments than it takes.

`@type` takes one argument (a type), `@mailbox` takes one (a `var[...]` expression), and
`@parameter` takes none — it is a bare marker. Supplying the wrong count is reported here, before
the annotation's content is looked at.

## Why it fires

```tla
---- MODULE Example ----
CONSTANTS
    \* @parameter: PID;
    PID
====
```

`@parameter` takes no argument; `: PID` is one too many.

## How to fix it

- Match the annotation to its shape: `@type: <type>`, `@mailbox: <var>[<indices>]`, `@parameter`
  alone.
- A `@type` with nothing after the colon, or a `@parameter` with a payload, is the usual cause.

## See also

- `E0004` — the argument count is right but the argument is the wrong kind of thing.
- `E0016` — the annotation is well-formed but not accepted at the site it sits on.
