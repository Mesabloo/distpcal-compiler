# E0012: 'while' inside a 'with' body

A `while` statement appears inside a `with` body, at any nesting depth.

A `while` loop spans multiple atomic steps — each iteration is its own block, reached by an
implicit `goto` back to the loop label. A `with` binding lasts one step. A loop inside a `with`
would need the binding to survive across those steps, which it does not.

## Why it fires

```tla
---- MODULE Example ----
(*--algorithm Example {
    variable x = 3;
    process (P = 0) {
    p1: with (y = 1) {
            while (x > 0) {
                skip;
            };
        };
        goto p1;
    }
}*)
====
```

The `while` is nested in `with (y = 1)`.

## How to fix it

- Move the `while` out of the `with`. Bind what it needs before the loop, or inside the loop body
  per iteration.

- `E0013` — a `while` not immediately preceded by a label.
