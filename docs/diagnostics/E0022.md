# E0022: ambiguous module

An `EXTENDS` clause names a module found in more than one place, with nothing to choose between
them.

Rather than silently pick one — and shadow the other — resolution reports both locations and
stops.

## Why it fires

`EXTENDS Helpers`, compiled with `-I libA,libB` where both `libA/Helpers.tla` and
`libB/Helpers.tla` exist. Both match `Helpers`; neither wins.

## How to fix it

- Remove the duplicate, or narrow the search path so only one directory on it provides the
  module.
- If the two files are meant to be different modules, rename one and update the `EXTENDS` clause.

## See also

- `E0021` — the module is on no search path at all.
- `E0059` — a file's declared module name does not match its file name.
