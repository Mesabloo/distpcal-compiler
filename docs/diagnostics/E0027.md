# E0027: missing type annotation

A construct needs a `@type` annotation to be checked, and does not have one.

An unbounded `\A x : P` or `\E x : P` has nothing to fix the bound variable's type — a bounded
`\A x \in S : P` gets it from `S`. Without a domain and without an annotation, `x`'s type is
unknown.

## Why it fires

```tla
---- MODULE Example ----
CONSTANTS
    \* @type: Address;
    PID

(*--algorithm Example {
    process (P = PID) {
    p1: assert \A x : x = x;
        goto Done;
    }
}*)
====
```

`\A x : x = x` has no domain for `x`.

## How to fix it

- Give the quantifier a domain: `\A x \in S : ...`. A distributed algorithm needs a finite one
  anyway (`E0054`).
- Where an annotation is accepted (a declaration, a binder), add `@type`.

## See also

- `E0028` — a type that cannot be inferred, where an annotation is not accepted anyway.
- `E0054` — an unbounded quantifier reachable from a statement.
