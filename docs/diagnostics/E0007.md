# E0007: malformed @mailbox annotation

A `@mailbox` annotation's expression parses, but is not of the form `var[e₁, …, eₙ]` (or a bare
`var`).

`@mailbox` names the channel a process receives on. That has to be a channel reference — a
declared `channels`/`fifos` name, optionally indexed — not an arbitrary expression.

## Why it fires

```tla
---- MODULE Example ----
CONSTANTS
    \* @type: Address;
    PID

(*--algorithm Example {
    fifos
        \* @type: Channel(Int);
        ch;
    \* @mailbox: ch + 1;
    process (P = PID) {
    p1: receive(ch, x);
        goto Done;
    }
}*)
====
```

`ch + 1` is a well-formed expression but not a channel reference.

## How to fix it

- Write the channel name, with one bracket group per index it is declared with: `ch`, `ch[self]`.
- For a process set, index by `self` so each instance gets its own FIFO (`E0063`).

## See also

- `E0064` — a process receives without any `@mailbox` at all.
- `E0006` — the `@mailbox` expression does not even parse.
