# E0047: shadowed name

A declaration reuses a name that is already in scope from an outer one.

A process-local `variables` entry with the same name as an algorithm-level declaration, or a
`with` binder with the same name as a variable already in scope (including an outer `with`). This
compiler does not allow the reuse — a name means one thing throughout.

## Why it fires

```tla
---- MODULE Example ----
CONSTANTS
    \* @type: Address;
    PID

(*--algorithm Example {
    fifos
        \* @type: Channel(Int);
        ch;
    process (P = PID)
        variables ch = 0;
    {
    p1: skip;
    }
}*)
====
```

The process-local `ch` shadows the algorithm-level channel `ch`.

## How to fix it

- Rename the inner declaration.
- If you meant to refer to the outer one, drop the inner declaration entirely.

## See also

- `E0046` — the same name declared twice in one scope.
- `E0015` — writing to a `with`-bound name.
