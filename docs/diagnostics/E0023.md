# E0023: cyclic EXTENDS

`EXTENDS` forms a cycle: a module extends, directly or through a chain, itself.

`EXTENDS` is a compile-time dependency — to resolve a module the compiler must first resolve
everything it extends. A cycle has no starting point, so it is rejected. The message shows the
chain, ending with the repeated name (`A -> B -> A`).

## Why it fires

```tla
---- MODULE A ----
EXTENDS B
====
```

```tla
---- MODULE B ----
EXTENDS A
====
```

`A` needs `B`, `B` needs `A`.

## How to fix it

- Break the cycle: move the shared declarations into a third module that both extend, and have
  neither extend the other.
- A cycle often means two modules that should be one — merge them.
