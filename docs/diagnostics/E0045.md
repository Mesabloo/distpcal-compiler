# E0045: 'Done' redefined

`Done` is used as an ordinary, user-defined label.

`Done` is reserved: it is the implicit label every process reaches when it runs off the end of its
body, and the target every `goto Done` resolves to. It cannot also name a block you wrote.

## Why it fires

```tla
---- MODULE Example ----
CONSTANTS
    \* @type: Address;
    PID

(*--algorithm Example {
    process (P = PID)
        variable x = 0;
    {
    p1: x := 1;
        goto Done;
    Done: x := 2;
    }
}*)
====
```

`Done:` here declares a real block, colliding with the reserved label.

## How to fix it

- Rename the block to anything else.
- `goto Done` still works — it always means "terminate this process".
