# E0058: internal invariant violated in Guarded2Network

A compiler bug, not a problem with your specification.

The pass that eliminates `receive` relies on facts the earlier passes establish — every
`receive`'s channel reference resolving to a `Channel(_)` type, for one. This diagnostic fires
when one of those did not hold. A program that gets this far through the pipeline should never
trigger it.

## Why it fires

A fact an earlier pass was supposed to have established did not hold. The message names it.

## How to fix it

- Report it, with the specification and the message text.
